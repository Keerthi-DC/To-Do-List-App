# Premium Pastel Lilac To-Do List Application

A responsive and modern To-Do List application built using React and Vite, featuring a light pastel lilac glassmorphism style.

## Features

- **Add Tasks**: Create new tasks easily with input validation.
- **Mark Completed**: Toggle completion status with a visual strike-through text effect.
- **Edit Tasks**: Edit existing tasks inline with a clean text box.
- **Delete Tasks**: Remove items instantly from the list.
- **Modern Theme**: Styled with a light lilac color palette, Outfit font, and soft shadows.

## Project Structure

- `src/App.jsx` - Main parent component managing state and handler functions.
- `src/components/Header.jsx` - Header branding section.
- `src/components/ToDoList.jsx` - Container that maps through to-do items.
- `src/components/ToDoItem.jsx` - Individual item rendering with toggle, edit, and delete functionality.
- `src/index.css` - Custom CSS design system.
